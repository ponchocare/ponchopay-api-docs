<ApiColumns>
  Sent when the payment is fully complete: the parent has taken all the necessary actions to make
  sure the payment will be correctly taken from the payment method they chose.

  That's when the parent finishes their part of checkout. For Standard Tax-Free Childcare and
  vouchers it comes before the [`payment_completed`](/webhooks/events/payment-completed/) webhook,
  which follows once the money is confirmed.

  PonchoPay sends the parent's browser back to your **Payment completed** redirect URL, set in
  **Settings → API integration**, with a form `POST`. Show them a confirmation page, or redirect
  them on.

  <Aside type="caution" title="Not proof of payment">
    A redirect comes from the parent's browser and isn't signed, so anyone could send one. Use it to
    show the parent what happens next, and rely on the
    [`payment_completed`](/webhooks/events/payment-completed/) webhook to update your system.
  </Aside>

  <Fragment slot="code">
    ```http title="Request to your site"
    POST /your/redirect/url HTTP/1.1
    Content-Type: application/x-www-form-urlencoded
    ```
  </Fragment>
</ApiColumns>

## Handle the redirect

<ApiColumns>
  Read `metadata` to find the payment in your system and show the parent its status. If
  `provider_redirect` is present, send the parent on to it when you're done, but only if it matches
  the redirect URL you hold for that provider. The form isn't signed, so an unchecked value would let
  anyone use your site to redirect people elsewhere.

  PonchoPay doesn't need a response, but the parent sees whatever you return, so return a page or a
  redirect.

  <Fragment slot="code">
    <Tabs syncKey="lang">
      <TabItem label="Express">
        ```js
        app.post('/ponchopay/payment-completed', express.urlencoded({ extended: false }), (req, res) => {
          const { metadata, provider_redirect } = req.body;

          // Look up by metadata to show status. Don't mark it paid here: wait for the webhook.
          if (provider_redirect && isKnownProviderUrl(provider_redirect)) {
            return res.redirect(303, provider_redirect);
          }
          res.redirect(303, `/orders/${encodeURIComponent(metadata)}`);
        });
        ```
      </TabItem>
      <TabItem label="PHP">
        ```php
        <?php

        $metadata = $_POST['metadata'] ?? '';
        $providerRedirect = $_POST['provider_redirect'] ?? null;

        // Look up by metadata to show status. Don't mark it paid here: wait for the webhook.
        if ($providerRedirect && isKnownProviderUrl($providerRedirect)) {
            header('Location: ' . $providerRedirect, true, 303);
            exit;
        }
        header('Location: /orders/' . rawurlencode($metadata), true, 303);
        ```
      </TabItem>
    </Tabs>
  </Fragment>
</ApiColumns>
