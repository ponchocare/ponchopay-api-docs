## How an integration works

<CardGrid>
  <Card title="1. Create a payment" icon="rocket">
    Your server signs a request with your integration key and calls
    [Initiate a payment](/endpoints/initiate-payment/). PonchoPay replies with a checkout URL.
  </Card>
  <Card title="2. The parent pays" icon="approve-check">
    Send the parent to the checkout. They pay by card, Pay by Bank, Tax-Free Childcare or
    childcare vouchers, or a mix.
  </Card>
  <Card title="3. Webhooks keep you in sync" icon="random">
    PonchoPay calls your URLs as the payment moves on: captured, completed, in bank. Start with
    [payment_completed](/webhooks/events/payment-completed/).
  </Card>
  <Card title="4. Reconciled for you" icon="document">
    PonchoPay matches payments to the provider's bank account and tells you when they're in bank
    (not available for every payment).
  </Card>
</CardGrid>

## Environments

| Environment | Base URL                          | Use it for                       |
| ----------- | --------------------------------- | -------------------------------- |
| Demo        | `https://demo.ponchopay.com/api/` | Building and testing, test cards |
| Production  | `https://pay.ponchopay.com/api/`  | Real payments                    |
