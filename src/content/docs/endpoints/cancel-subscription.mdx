<ApiColumns>
  Cancels a recurring payment (subscription) so it takes no more payments, for example when a
  child leaves the club.

  PonchoPay sends [`recurring_payment_cancel`](/webhooks/events/recurring-payment-cancel/) after
  the change.

  <Fragment slot="code">
    <Endpoint method="PUT" path="/api/recursion/{id}/cancel" />
  </Fragment>
</ApiColumns>

## Authentication

<ApiColumns>
  Send a [management JWT](/getting-started/authentication/#management-jwt) in the `Authorization`
  header. There's no body, so `sig` is the hash of an empty string. The SDKs build the token for
  you.

  <Fragment slot="code">
    ```http
    PUT /api/recursion/{id}/cancel
    Authorization: Bearer <jwt>
    ```
  </Fragment>
</ApiColumns>

## Returns

<ApiColumns>
  **`204 No Content`**: the recurring payment was cancelled.

  **`400 Bad Request`**: the recurring payment couldn't be cancelled.

  Requests with an invalid or expired token, or for a recurring payment that doesn't belong to the
  token's location, are rejected.

  <Fragment slot="code">
    ```http title="Response"
    HTTP/1.1 204 No Content
    ```
  </Fragment>
</ApiColumns>
