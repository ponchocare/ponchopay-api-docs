<ApiColumns>
  Cancels a payment so the parent can no longer pay it, for example when a booking is cancelled
  before the parent has paid. To give money back on a payment that's been paid, use
  [Refund a payment method](/endpoints/refund-payment-method/).

  PonchoPay sends [`payment_cancelled`](/webhooks/events/payment-cancelled/) after the change.

  <Fragment slot="code">
    <Endpoint method="PUT" path="/api/payment/{id}/cancel" />
  </Fragment>
</ApiColumns>

## Authentication

<ApiColumns>
  Send a [management JWT](/getting-started/authentication/#management-jwt) in the `Authorization`
  header. There's no body, so `sig` is the hash of an empty string. The SDKs build the token for
  you.

  <Fragment slot="code">
    ```http
    PUT /api/payment/{id}/cancel
    Authorization: Bearer <jwt>
    ```
  </Fragment>
</ApiColumns>

## Returns

<ApiColumns>
  **`204 No Content`**: the payment was cancelled.

  **`400 Bad Request`**: the payment couldn't be cancelled. An invalid or expired token, or a
  payment that doesn't belong to the token's location, is also rejected.

  <Fragment slot="code">
    ```http title="Response"
    HTTP/1.1 204 No Content
    ```
  </Fragment>
</ApiColumns>
