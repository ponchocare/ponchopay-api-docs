<ApiColumns>
  Sent when the parent has finished setting up a recurring payment and PonchoPay has everything it
  needs to take its payments. The parent is also sent to your
  [Subscription set up](/redirects/subscription-set-up/) redirect URL.

  Use it to mark the membership or plan as active in your system.

  <Fragment slot="code">
    <Event name="recurring_payment_set_up" setting="Recurring payment set up" />
  </Fragment>
</ApiColumns>

## The event

<ApiColumns>
  PonchoPay sends a `POST` with the [standard headers](/webhooks/overview/#request-format) and a
  [SubscriptionCallback](/objects/subscription-callback/) body, with `event` set to `recurring_payment_set_up`:

  <Fields schema="SubscriptionCallback" />

  <Fragment slot="code">
    <Example schema="SubscriptionCallback" title="Example body" overrides={{ event: 'recurring_payment_set_up', 'request.metadata': 'membership-2291', 'subscription.payment_methods.0.amount': 8500, 'subscription.payment_methods.0.id': 'b7d9f1a3-4c6e-4a8b-9d0f-3e5a7c9b1d42' }} />
    The values are examples. `request.metadata` is the `metadata` you sent when you created the
    recurring payment.
  </Fragment>
</ApiColumns>
