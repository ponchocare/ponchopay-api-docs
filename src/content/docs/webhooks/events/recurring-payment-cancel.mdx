<ApiColumns>
  Sent when a recurring payment has been cancelled in the admin, or through
  [Cancel a subscription](/endpoints/cancel-subscription/). Once cancelled, it no longer generates
  payments. Payments already taken aren't affected.

  Note the event name: `recurring_payment_cancel`, not `recurring_payment_cancelled`.

  <Fragment slot="code">
    <Event name="recurring_payment_cancel" setting="Recurring payment cancel" />
  </Fragment>
</ApiColumns>

## The event

<ApiColumns>
  PonchoPay sends a `POST` with the [standard headers](/webhooks/overview/#request-format) and a
  [SubscriptionCallback](/objects/subscription-callback/) body, with `event` set to `recurring_payment_cancel`:

  <Fields schema="SubscriptionCallback" />

  <Fragment slot="code">
    <Example schema="SubscriptionCallback" title="Example body" overrides={{ event: 'recurring_payment_cancel', 'request.metadata': 'membership-2291', 'subscription.payment_methods.0.amount': 8500, 'subscription.payment_methods.0.id': 'b7d9f1a3-4c6e-4a8b-9d0f-3e5a7c9b1d42' }} />
    The values are examples. `request.metadata` is the `metadata` you sent when you created the
    recurring payment.
  </Fragment>
</ApiColumns>
